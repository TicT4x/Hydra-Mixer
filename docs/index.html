Hydra Mixer Wiki

Hydra Mixer is a virtual audio mixer for Windows built for the lowest possible latency, an alternative to Voicemeeter Potato. This page walks you through the setup step by step and explains every feature for later reference.

Version 0.6 System Windows 10 / 11, 64-bit, AVX2 Drivers ASIO · WASAPI Plugins VST3 Control MIDI · hotkeys

Where do I start?

New here?

The tutorial takes you from download to your first mix in 10 minutes.

Coming from Voicemeeter?

Import your settings and learn the differences.

Got a specific goal?

Recipes: stream mix, clean up a mic, bring in Spotify …

Having a problem?

No sound, crackles, yellow dots: solutions.
Status: early release. The mixer, the UI and the DSP are complete and covered by offline tests. Real-world signal flow with different hardware (several ASIO devices, loopback, VST3, MIDI controllers) has seen little testing so far. Bug reports are welcome: GitHub Issues.

1Installation

  1. Download HydraMixer-0.6-win64.zip from the Releases page.
  2. Unzip it anywhere, e.g. C:\Tools\Hydra Mixer. There is no installer and no runtime to install.
  3. Start Hydra Mixer.exe. On first start Hydra picks a default device. Then choose your master device in the Settings.

Requirements

  • Windows 10 or 11, 64-bit.
  • A CPU with AVX2 (practically every Intel CPU since 2013 and AMD CPU since 2015).
  • Recommended: an audio interface with an ASIO driver. Without ASIO, Hydra works with Windows audio (WASAPI), with somewhat higher latency.

Building from source

You need the Visual Studio 2026 Build Tools (MSVC, C++ workload), CMake 3.25 or newer and Ninja.

git clone --recursive https://github.com/TicT4x/Hydra-Mixer.git
cd Hydra-Mixer
.\build.ps1                # Release
.\build.ps1 -Config Debug

The app ends up in build\Release\HydraMixer_artefacts\Release\Hydra Mixer.exe, the tests in build\Release\HydraTests_artefacts\Release\HydraTests.exe.

2Tutorial: first steps

In this tutorial you set up a typical mix: microphone and game/music in, headphones and stream out.

Step 1: choose the master device

  1. Click the gear at the top right (or the status text with the driver name in the top bar). Settings → Audio Engine opens.
  2. Under Driver choose ASIO and your interface below it. Without ASIO, use Windows Audio (Low Latency Mode).
  3. Set the Sample rate (usually 48000) and the Buffer size. Smaller buffer = less latency but more CPU load. With ASIO the buffer size is often set in the ASIO Control Panel.
  4. Click Apply / Restart.
Why does this matter? The master device is the clock of the whole mixer. Its inputs and outputs run without any extra buffer, so with the lowest latency. Everything else is adapted to this clock. More under Core concepts.

Step 2: put the microphone on an input

  1. In the first input strip, click the device chip below the channel name. The device picker opens.
  2. On the left choose Master (or Hardware), on the right your microphone's channel, e.g. Mono 1. A click applies it right away, a double-click applies and closes.
  3. Speak into the microphone. The level meter in the strip moves. If it is too quiet, turn the GAIN knob at the top of the strip.
  4. Double-click the channel name to rename it, e.g. to “Mic”.

Step 3: bring in a game or music

  1. Open the device picker of the second input and choose Application.
  2. Choose the app, e.g. Spotify.exe. The list only shows apps that are playing audio right now. If it is missing, start playback and click Refresh.
  3. So you don't hear the app twice, set its output in Windows Settings → System → Sound → Volume mixer to a device you don't listen to.

Alternatives: Loopback captures everything Windows plays on a playback device. More under Virtual devices.

Step 4: set up the outputs

  1. On the right you see the Hardware Outputs (A1, A2, …) and the Virtual Outputs (B1, B2, …).
  2. On bus A1 click the device chip and choose your headphones or speakers.
  3. For a stream mix, send B1 e.g. to a virtual cable that OBS records as a microphone (see Virtual devices), or record B1 with the Recorder.

Step 5: routing

  1. Every input strip has routing buttons A1 A2 A3 … and B1 B2 …. A lit button means: this input goes to this bus.
  2. For the microphone, turn on e.g. B1 (stream); for the music A1 and B1 (you hear it, the stream too).
  3. Use the faders to set the volume. Clicking the dB value below a fader lets you type a value, e.g. -6.

Step 6: improve the microphone

  1. Click the mic strip. Its effects appear in the Inspector at the bottom.
  2. Turn on the Denoiser (removes fans, keyboard, hiss).
  3. Optional: EQ with a low cut at about 80 Hz, Gate with Voice Key, Compressor with Auto Gain.
Done. Hydra saves every change automatically after about 2 seconds. There is nothing to save by hand. Worth looking at next: MIDI Learn, keyboard shortcuts and scenes.

3Core concepts

Inputs, hardware and virtual outputs

TermCountMeaning
Input (IN 1–16)up to 16, default 8A signal source: microphone, interface channel, app, loopback, virtual cable. Every input has its own effect chain.
Hardware Output (A1–A8)up to 8, default 5An output bus, usually to real outputs (headphones, speakers).
Virtual Output (B1–B8)up to 8, default 3A bus for mixes you don't listen to directly: stream, recording, Discord. Can also be sent to a device (e.g. a virtual cable).

A and B buses work the same way technically. The differences are the grouping in the interface, the Recorder records B buses, and monitoring replaces an A bus.

Signal flow

Every input runs through this chain, in this order:

Source→Gain→Denoiser→EQ (8 bands)→Gate→Compressor→VST3 chain→Sync Delay→Mono→Fader / Pan→Routing A/B

Every bus sums the routed inputs and processes them further:

Sum→EQ→VST3 chain→Mono→Fader / Mute→Limiter→Sync Delay→Output device

The master device as the clock

Every audio device has its own clock, and no two clocks run at exactly the same speed. Hydra solves this like this:

  • The master device (ideally ASIO) is the only clock. Its channels add no extra latency.
  • All other devices are attached through a ring buffer and a resampler. A self-tuning drift compensation keeps adjusting the sample rate very slightly so the buffer never runs empty or overflows. This costs a few milliseconds of latency.
  • Several channels of the same interface stay sample-accurate to each other.
Rule of thumb: put the devices where latency matters (microphone, headphones) on the master device. Apps, loopback and second devices are perfectly fine for music, games and streams.

Automatic saving

Every change is saved to session.xml after about 2 seconds. A backup is also made at every start (up to 40). See Backup & Transfer.

6Strips

Input strip

From top to bottom:

  • Name: double-click to rename.
  • Device chip: the current source. A click opens the device picker. Coloured dots left of the name show problems (see below).
  • GAIN: input gain before all effects.
  • Routing buttons: A1, A2, … and B1, B2, … (three per row, only buses in use).
  • MONO, SOLO, MUTE.
  • Fader with level meter and dB display, pan below.

A click anywhere in a strip selects it in the Inspector. When a channel is muted or silenced by solo, the meter shows in grey the level it would have without mute.

Bus strip

Name, output device, SEL (see SEL & monitoring), MONO, MUTE, fader with meter.

Status dots on the device chip

DotMeaning
RedDevice offline (unplugged, in use or failed).
YellowDropouts in the last 2 minutes, or a notice: waiting for the app, “Hydra Virtual” without a driver.

Hover over the dot: the tooltip explains the problem, for dropouts with count and age (“12 s ago”).

Dividing the space

Between inputs and outputs there is a divider. Drag it to shift the space, double-click for the default split. The mouse wheel scrolls the strips sideways. If the window is too low, the strips are scaled down instead of scrolling vertically.

8Managing channels

Adding

Click the + next to the heading Inputs, Hardware Outputs or Virtual Outputs. The next free slot is activated (max. 16 inputs, 8 A and 8 B buses).

Renaming and removing

Right-click the header or background of a strip → Rename or Remove. Removing resets the channel's settings, plugins, MIDI mappings and shortcuts (with confirmation). At least one input and one A bus always remain.

Changing the order

  1. Right-click a strip → Change Order.... A bar with Done and Discard appears above the strips.
  2. Drag the strips within their group (inputs, A buses, B buses) to the place you want.
  3. Done (Enter) applies, Discard (Esc) throws it away.

A channel gets the number of its new position. For buses, routing, sends, recorder and monitor settings move along. If MIDI mappings or shortcuts sit on moved channels, Hydra asks:

  • Follow the channels: your controller keeps controlling the same channels, now at their new position.
  • Keep positions: every hardware control stays on its position (fader 1 still controls strip 1, which is now a different channel).

Afterwards the undo history is cleared.

How to use it

  • A click on a channel applies it right away, the window stays open. A double-click applies and closes.
  • Devices with only one option (apps, cables, loopback) are chosen with the click on the device.
  • Dots mark the path to the current choice, a tick marks the current channel.
  • Channels come as stereo pairs (Stereo 1/2, …) or mono.
  • Refresh rescans devices and apps. Esc, Enter or Done close the window.
  • The window follows the strip you clicked last, so you can set up several channels one after another.
Several ASIO interfaces Under Other ASIO Devices you can use more ASIO drivers next to the master. A driver is opened only once, with the buffer size from its own control panel. If it restarts (e.g. after a change in its control panel) or hangs, Hydra reopens it automatically.

11Denoiser

Every input has a built-in noise suppressor based on RNNoise, a neural network for speech. It removes fans, keyboard clatter, hum and room noise. It is off by default.

Controls

ControlMeaning
DENOISER ONOn/off.
AMOUNTMix of the original and the denoised signal. Both are aligned exactly in time, so there are no comb-filter effects.
Latency mode (in the … menu)See table.
ModeLatencyNote
Ultra Low0 msNo delay; word onsets can suffer slightly.
Low (default)10 msGood compromise for live speech.
Aligned20 msBetter quality.
Native HQ30 msRNNoise's original behaviour, best quality.

Cost: about 1.8 % of one CPU core per stereo channel.

48 kHz only RNNoise works at 48 kHz. If the engine runs at a different sample rate, the denoiser is bypassed and the UI shows a notice.

The arrow button in the EQ header opens a separate window with a large curve, all bands with their values and a live spectrum of the signal after the EQ (scale on the right in dBFS). The window follows the selected channel. The spectrum is only computed while the window is open.

13Correction

Room, speaker or headphone correction in every input and every bus: up to 32 filter bands plus a preamp, zero latency. In an input it sits right after the gain (before the denoiser), in a bus after the plugins. The section in the Inspector shows the curve, the profile's name and size; ON switches it (MIDI-learnable, undo, scenes).

Click the curve or … for the menu:

  • Measure room / speaker: opens the Room Measurement; its Auto Correction fills this stage.
  • Import headphone profile (AutoEq / Equalizer APO): reads a parametric EQ file, e.g. a ParametricEQ.txt from the AutoEq project for your headphones (Preamp + “Filter: ON PK / LSC / HSC …” lines).
  • Import room / speaker profile: the same format, marked as a room / speaker correction.
  • Type, Export as Equalizer APO file, Clear.

The profile is stored with the session and moves with its channel when channels are reordered.

14Gate & Voice Key

A gate silences the channel while the signal stays below a threshold, e.g. so the microphone doesn't transmit background noise between sentences.

ControlMeaning
THRESHOLDLevel at which the gate opens.
RANGEHow much it attenuates when closed (e.g. −80 dB = practically silent, −10 dB = just quieter).
ATTACKHow fast the gate opens.
HOLDHow long it stays open at least.
RELEASEHow fast it closes afterwards.
SIDECHAIN BP + SC FREQThe gate only “listens” to one frequency range, e.g. to ignore low hum.
VOICE KEY + VOICE THRThe gate only opens when the level is above THRESHOLD and the denoiser detects speech (probability above VOICE THR).
Voice Key needs the denoiser switched on. Without it the gate works as a normal level gate. With Voice Key, keyboard, coughs and clicks stay out even when they are loud.

15Compressor

The compressor evens out volume differences: loud parts are turned down, the result is more even. A transfer curve shows the effect including the current gain reduction.

ControlMeaning

THRESHCompression starts above this level.
RATIOStrength. 4:1 means: 4 dB more input gives 1 dB more output.

16VST3 plugins

Every input and every bus has a VST3 Insert Chain. The plugins run in order, without extra buffering (their own latency is shown by the Latency Finder).

Setting up plugins

  1. Settings → Plugins: enter search folders (one per line, the default is the usual VST3 folder) and click Scan for plugins. A plugin that crashes during the scan is remembered and skipped from then on.
  2. In the inspector: + Add VST3 Plugin (empty chain) or the + after the last card.

How to use it

  • Open the editor: double-click the card or EDIT.
  • Order: drag & drop the cards.
  • Bypass: per plugin on its card, for the whole chain with BYPASS in the section header.
  • Remove: trash can icon.
  • PHASE in the section header (inputs) inverts the polarity.
Stability The audio thread never waits for a plugin that is being loaded or edited. If a plugin can't be loaded, the card says “Plugin could not be loaded”.

17Buses & limiter

Every bus has a fader, mute, mono, the 8-band EQ, a VST3 chain, a limiter and a freely selectable output device.

Limiter

The limiter at the end of the bus keeps the level from rising above CEILING, e.g. so a stream never clips. It adds no latency.

Sends

Every input has its own send level per bus (default 0 dB), applied after the strip fader. You set it with SEL.

18SEL & monitoring

SEL: a separate mix per bus

When you press SEL on a bus, the input faders no longer control the overall volume but only each input's level on this bus. Inputs not routed there are dimmed. This lets you build e.g. a stream mix where the music is quieter than in your headphones.

  1. Press SEL on B1. The faders jump to the send levels for B1.
  2. Pull the music fader to −12 dB. The music is now quieter on the stream, unchanged in your headphones.
  3. Press SEL again to return to the normal view.

Only one bus can have SEL at a time. A MIDI fader that controls an input's main fader also controls the send while SEL is active; motor faders jump along.

Monitoring

In Settings → General → MONITORING (SEL) turn on Monitor selected bus and choose the Monitor output (A1–A5). The SEL bus then replaces the sum of this A bus: on your headphones you hear exactly the mix you are editing (e.g. the stream). EQ, fader and limiter of the monitor bus still apply.

Waveform, seek and trim

  • The waveform grows live while recording.
  • Clicking or dragging in the waveform jumps there. While stopped, this sets the start point for play.
  • Dragging the handles at the left and right edge inwards sets the in and out points (non-destructive, outside is greyed out). Playback and loop stay within this range.
  • Cut writes the range to the file (WAV: the original goes to the Recycle Bin; other formats: new file name_trimmed.wav). Reset moves the handles back.

WAV, AIFF, FLAC, Ogg and MP3 can be played, with automatic sample rate conversion. Last Take loads the most recent recording.

21Latency Finder

Tools → Latency Finder shows how much delay every path from input to output has and where it comes from. It is the only place in Hydra that shows latency values.

Layout

  1. Matrix (top): inputs × outputs with the total latency of every routed path. Click a cell to see exactly this path.
  2. Signal flow: input device → denoiser → each plugin → sync delay → bus plugins → output device. Each stage shows “+x ms” (what it adds), its share in % and “at y ms” (the sum so far).
  3. Latency share: donut and ranking of the shares for the selected path.

Hovering over an input or output device explains in a tooltip what its latency is made of (buffer, driver/converter, clock sync buffer) and how to reduce it. Clicking a row also selects the channel in the main window.

Reducing latency
  • Smaller buffer size in the ASIO control panel or in Settings → Audio Engine.
  • Put important channels on the master device (no clock sync buffer).
  • Windows devices in Exclusive or Low Latency mode instead of Shared.
  • Denoiser mode Ultra Low or Low.
  • Switch plugins with lookahead to their zero-latency mode or bypass them.

22Sync Delay

Different devices have different latency. If, for example, one source arrives over a slower path than the microphone, or two outputs drift apart in time, Sync Delay lines them up.

Open: Tools → Sync Delay. For each group (inputs, hardware outputs, virtual outputs) you see every channel with:

ColumnMeaning
LATENCYThe channel's own latency.
AUTO SYNCSwitch. All channels of a group with Auto sync are delayed to the slowest of them. The slowest one is marked “slowest: sets the time”.
AUTO DELAYAutomatically computed delay, follows the live latency.
MANUAL DELAYExtra delay by hand (0–500 ms), e.g. for a microphone that is further away or for lip sync on a stream.
RESULTTotal. The bar shows own latency (solid) and delay (hatched).

Sync all / Sync none switch Auto sync for the whole group. Delay values can be MIDI-learned and are part of undo and scenes. Changes are applied with a short crossfade.

23DSP Load

Click the DSP meter in the top bar (or Tools → DSP Load) to see what costs how much processing time. Values are shares of the time available per audio block, averaged over 1 second, with peak.

  • Total load as a bar with peak marker.
  • Biggest consumers: the three most expensive stages.
  • Table: one row per channel in mixer order, columns Denoiser / EQ / Gate / Comp / Plugins / Limiter / Rest. Cells are tinted by load.
  • Engine row: resampling of secondary devices, recorder, mixing.

Measuring only happens while the window is open. Clicking a row selects the channel in the mixer.

Guideline Below about 50 % you are on the safe side. If the peak approaches 100 %, crackles are likely: increase the buffer or reduce expensive plugins/denoisers.

24Room Measurement

Measures how your speakers sound in your room, finds the room's resonances (boomy bass notes that keep ringing) and designs an EQ that flattens them. Open: Tools → Room Measurement.

Setup

  • Microphone (input): the input strip whose source is your measurement microphone, plus its channel (left / right). Hydra takes the signal straight from the device, before trim, denoiser, EQ, gate, compressor and plugins.
  • Mic calibration: the microphone's own frequency response, taken out of the result. Presets: t.bone EM 700 (data sheet, from 500 Hz) and (full data sheet curve). Import calibration file… reads the calibration of your microphone (REW / miniDSP UMIK / Dayton: one “frequency dB” pair per line); imported files are kept in %APPDATA%\HydraMixer\Calibrations. Right-click a saved measurement to analyse it again with another calibration.
  • Speaker (output bus): the bus that plays on the speakers to measure, and whether the sweep plays on left, right or both. While measuring, the sweep replaces everything on this bus; its EQ, plugins, fader and limiter are skipped.
  • Sweep / Sweeps / Level: length of the sine sweep (2–10 s), how many sweeps are averaged, and their level. Start low and raise the level until the mic peak is around −20 to −6 dBFS.
  • Mute all other outputs (on by default): music or voice chat would disturb the measurement.
  • Through the output's EQ + Correction: the sweep passes the bus's EQ and Correction. Use it after applying a correction to check the result.

Put the microphone at the listening position (ear height, pointing up), keep the room quiet and click Start measurement. The bar shows the phase (background noise, sweep n of m, decay) and the microphone level.

Results

ViewShows
ResponseFrequency response (smoothing 1/3 to 1/24 octave), red markers on the resonances, and with Auto EQ: the EQ curve, the target and the response with the EQ. Compare overlays a second measurement (e.g. before / after).
Waterfall 3DCumulative spectral decay: the spectrum 0–300 ms after the direct sound, back to front. Ridges that reach far to the front are frequencies that keep ringing (room modes). Drag to tilt, double click to reset.
Decay (RT60)Reverberation time per octave band (T20, early decay EDT). 0.2–0.5 s is typical for small rooms and studios.
ImpulseEnergy over time: direct sound, reflections, decay into the noise.

The Resonances list shows every peak below 400 Hz that stands out of its surroundings by more than 3 dB, with its width (Q) and how long it rings (time until it has decayed by 20 dB).

Auto Correction

Designs up to 24 bell bands that bring the response as close to a flat target as the limits allow. From / To: the corrected range (room modes live below ~300–500 Hz; a near-field speaker measurement can be corrected up to 20 kHz). Max cut / Max boost: dips are usually cancellations that a boost cannot fill, so boosting is off by default; with boosts, a preamp keeps the result from clipping. Type: room, speaker or headphone. Apply to … Correction puts the bands into the chosen channel's Correction (usually the measured bus) and switches it on. Export… saves them as an Equalizer APO file.

Library & export

Every measurement is saved in %APPDATA%\HydraMixer\Measurements and listed on the left (double click to rename). Export: measurement file (.hydrameasure, can be imported again), frequency response as text (REW), impulse response (WAV), waterfall (CSV), chart as image (PNG).

Tip Measure, apply the correction to the bus, then measure again with Through the output's EQ + Correction and compare both in the Response view.

25Undo / redo

Ctrl+Z undoes the last change, Ctrl+Y (or Ctrl+Shift+Z) redoes it. This works in the main window and in all tool windows. A notice shows what was undone.

  • All saved parameters are tracked in one history: faders, routing, EQ, gate and so on. Up to 200 steps.
  • A step is created once a movement is finished (mouse released and a short pause).
  • Not tracked: changes by MIDI, adding/removing channels, names, devices, plugins.

26MIDI Learn

Every control and switch in Hydra can be operated with a MIDI controller.

Setup

  1. Settings → MIDI: enable your controller under MIDI inputs (controllers). Optionally choose the same controller as Feedback output (for LEDs and motor faders).
  2. Right-click a control → MIDI Learn.
  3. Move the hardware control or press the button. Done.

For many assignments in a row: Tools → MIDI Learn Mode. Then a left click on the control and a move on the controller is enough, for as many controls as you like. The wrench turns yellow and the status line shows a hint.

Modes

ModeBehaviourFor
AbsolutePosition of the hardware control = value.Faders, pots
ToggleEvery press switches.Mute buttons
MomentaryOn while held.Push-to-talk
RelativeEndless encoders send steps.Encoders without end stops

CC, note and pitch bend are supported. Every mapping can be inverted.

MIDI Map

Tools → MIDI Map lists all mappings in a table: change mode, invert, range, delete single mappings or Remove all.

MIDI range

Right-click → MIDI Range (calibrate) sets which value range the hardware control covers, e.g. only −∞ to 0 dB. This gives you finer resolution in the range you use. Options: current value as minimum/maximum, presets (Fader: -inf .. 0 dB, -inf .. +6 dB, Full range) or type values in the MIDI Map. A yellow bar on the fader shows the range. Feedback to motor faders is scaled accordingly.

Globally: Settings → MIDI → MIDI faders stop at 0 dB sets the maximum of all fader mappings to 0 dB (instead of +12 dB), also for faders learned later.

30Backup & Transfer

Automatic backups

Hydra keeps a copy of your settings at every start and before every import (up to 40, duplicates are skipped). In Settings → Backup & Transfer → Automatic Backups pick one and click Restore. Open Folder shows the folder.

Export / import

Export Settings... saves all settings to a file, e.g. for another PC. Import Settings... loads them (the current ones are backed up first).

Safety measures

  • The session file is written atomically, a crash while saving doesn't damage it.
  • An unreadable session.xml is moved aside instead of overwritten.
  • If the file was changed from outside, Hydra backs it up before the next save.

31Voicemeeter import

If you are coming from Voicemeeter Potato, you can take over your settings.

  1. In Voicemeeter: Menu → Save Settings saves an XML file (often in Documents).
  2. Close Voicemeeter so the ASIO driver is free.
  3. In Hydra: Settings → Backup & Transfer → Import from Voicemeeter. Hydra looks in Documents, otherwise use Browse.... Then Import.

Taken over: devices, ASIO channel patches, names, routing, EQ, gate, compressor, denoiser and the MIDI mappings (existing Hydra mappings stay, except on conflicts). Your current Hydra settings are replaced, but backed up first.

32Virtual devices (Hydra as speaker/microphone)

Voicemeeter installs its own Windows audio devices that any app can choose as speaker or microphone. Hydra doesn't have such a driver (yet): a Windows audio driver only loads with Secure Boot on if it is signed through Microsoft with an EV certificate; otherwise it needs test mode, which breaks games with anti-cheat. So for now:

  • Apps can't select “Hydra” as their playback device.
  • Discord, OBS or Teams can't select a B bus directly as their microphone.

Solutions

1. Application (built in)

Captures the audio of a single app. Nothing to install. Set the app's output in the Windows volume mixer to a device you don't listen to.

2. Loopback (built in)

Captures everything Windows plays on a playback device. Somewhat more latency.

3. VB-CABLE (free)

Install VB-CABLE. In: app → CABLE Input, a Hydra input records CABLE Output. Out: B bus → CABLE Input, OBS/Discord use CABLE Output.

4. Virtual Audio Cable (paid)

VAC offers any number of freely named cables. Detected automatically.

5. Voicemeeter's devices

If Voicemeeter is installed, its playback devices stay usable: the app plays to “Voicemeeter Input”, Hydra captures it with loopback. Close Voicemeeter itself.

Settings → Virtual Cables lists all detected cables. Auto-assign cables gives every “Hydra Virtual” placeholder (e.g. from a Voicemeeter import) the next free cable.

33Recipes

Stream mix with its own music volume

  1. Route microphone and music to A1 (headphones) and B1.
  2. Send B1 to a virtual cable, use the other end as an audio source in OBS.
  3. SEL on B1, music fader to about −15 dB. SEL off.
  4. Optional: limiter on B1 with a ceiling of −1 dB.

Clean microphone for calls

  1. Denoiser on (mode Low), amount 100 %.
  2. EQ: low cut at 80 Hz, bell +2 dB at 3 kHz.
  3. Gate on with Voice Key, threshold just above the noise floor.
  4. Compressor: ratio 3:1, auto gain on.
  5. Discord mix on B2 → virtual cable → Discord microphone.

Push-to-talk / mute key in a game

  1. Right-click the microphone's MUTE → Assign Keyboard Shortcut → e.g. Ctrl+F12 or the mouse's thumb button.
  2. For push-to-talk by MIDI: learn the button and choose mode Momentary in the MIDI Map (with invert, so pressing = unmuted).

Switching between setups

  1. Set up the mixer for “Gaming”, new scene in the Scene Editor, Save.
  2. Repeat for “Stream”.
  3. Right-click each scene → keyboard shortcut or MIDI button.

Picture and sound in sync on a stream

  1. Read the latency of the stream bus in the Latency Finder.
  2. In Sync Delay set a manual delay on the microphone input until lips and sound match, or use Auto sync in the group.

Recording a session

  1. Route everything that should be on the recording to B3.
  2. Recorder: Record Source B3, format WAV 24, press record.
  3. Afterwards set start/end with the trim handles and Cut.

35Troubleshooting

No sound at all

  • Check the status text in the top bar: if it says the engine is stopped, click it and choose a device in Settings → Audio Engine.
  • Is the input routed to a bus, and does the bus have an output device?
  • Mute, solo on another channel, fader at −∞?
  • Is Voicemeeter or a DAW running that holds the ASIO driver? Close it.
  • If the driver silently stops delivering audio: Tools → Restart Audio Engine.

Crackles and dropouts

  • Yellow dot on the device chip? The tooltip shows how many dropouts and when.
  • On the master: increase the buffer size (e.g. from 64 to 128 samples).
  • Open DSP Load: if the peak is near 100 %, reduce expensive plugins or denoisers.
  • Set the Windows power plan to “High performance”, avoid Bluetooth devices.

Red dot on a device

The device is offline: unplugged, held exclusively by another app or the driver crashed. Hydra reopens secondary ASIO devices automatically. Otherwise choose the device again or use Restart Audio Engine.

Yellow dot “waiting for app”

The chosen app isn't running or isn't playing audio right now. Hydra connects automatically as soon as it plays.

Yellow dot “Hydra Virtual”

A placeholder from a Voicemeeter import. Assign a real source or use Settings → Virtual Cables → Auto-assign cables.

App missing from the “Application” list

Only apps that are playing audio right now appear. Start playback, then Refresh.

I hear an app twice

With application capture the app keeps playing to its Windows device. In the Windows volume mixer, set its output to a device you don't listen to.

Denoiser has no effect

The engine isn't running at 48 kHz. Set the sample rate to 48000 in Settings → Audio Engine.

Global shortcut doesn't work in a game

Use a combination with Ctrl or Alt, or an F key. If Hydra reports that it is taken by another app, choose a different combination.

Settings gone or broken

Settings → Backup & Transfer → Automatic Backups → pick a backup → Restore.

37Glossary

ASIOSteinberg's driver interface for audio interfaces with very low latency. Only one program can use a driver at a time.
WASAPIThe Windows audio interface. Shared = several apps share the device, Exclusive = one app alone, Low Latency = shared with a small buffer.
Master deviceThe device whose clock drives the whole mixer.
Buffer / buffer sizeNumber of samples per processing block. 128 samples at 48 kHz ≈ 2.7 ms.
LatencyDelay between input and output.
Dropout / xrunA block arrived too late or was missing, audible as a crackle.
DriftTwo device clocks run at slightly different speeds. Hydra compensates by resampling.
LoopbackCapturing what a playback device plays.
BusSum of several inputs with its own processing and its own output.
SendThe level at which an input goes to a particular bus.
InsertAn effect directly in a channel's signal path.
dBFSDecibels relative to digital full scale (0 dBFS = maximum).
QQuality of an EQ band: high = narrow, low = wide.
RNNoiseFree noise suppression based on a neural network (Xiph.org).
VST3Plugin format for audio effects.
